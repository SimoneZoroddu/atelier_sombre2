# Atelier Sombre

A full stack fashion e-commerce inspired by luxury online stores, developed during the Full Stack Web Development training.

## Preview

Modern and responsive shopping experience featuring product browsing, wishlist management, cart functionality and checkout flow.

## Features

- Product catalog with categories
- Product detail pages
- Available size management
- Shopping cart with persistent storage
- Wishlist / Favorites system
- Suggested products
- Responsive design
- Checkout flow
- Order confirmation email integration with Mailtrap
- Dynamic data from database
